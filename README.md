☕ Starbucks Dataset — Exploratory Data Analysis (EDA)

This project focuses on Exploratory Data Analysis (EDA) of the Starbucks beverage dataset using Python. The analysis explores nutritional information across different Starbucks beverage categories to identify patterns, relationships, and interesting insights within the dataset.

📊 Scope of Analysis

The notebook covers:

- Data inspection to understand the dataset structure, features, and data types
- Data cleaning and preprocessing
- Handling missing and inconsistent values
- Descriptive statistical analysis of nutritional attributes
- Analysis of categorical and numerical variables
- Data visualization using:
  - Bar charts
  - Histograms
  - Box plots
  - Correlation heatmaps
- Interpretation of patterns and relationships within the dataset

🔍 Key Observations

- A strong relationship was observed between calories, sugar, and carbohydrate content.
- Frappuccino-based beverages generally contain higher calorie and sugar values.
- Brewed coffee and tea options generally contain fewer calories.
- Caffeine content varies across beverage categories and does not always follow the same pattern as calories or sugar.
- Nutritional attributes show different distributions across beverage categories.

🛠️ Tools & Technologies

- Pandas — Data manipulation and analysis
- NumPy — Numerical computing
- Matplotlib — Data visualization
- Seaborn — Statistical visualization
- Jupyter Notebook — Interactive analysis
