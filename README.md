## 📌 Project Overview

This project focuses on Exploratory Data Analysis (EDA) of the Starbucks beverage dataset using Python.

The analysis explores nutritional information across different Starbucks beverage categories to identify patterns, relationships, distributions, and meaningful insights within the dataset.

The project demonstrates the fundamental workflow of data analysis, including:

- Data inspection
- Data cleaning
- Data preprocessing
- Statistical analysis
- Data visualization
- Correlation analysis
- Interpretation of results

---

## 📊 Scope of Analysis

### 🔎 Data Inspection

- Understanding the dataset structure
- Examining features and data types
- Checking dataset dimensions
- Identifying numerical and categorical variables
- Inspecting unique values
- Checking for missing values

### 🧹 Data Cleaning & Preprocessing

- Handling missing values
- Identifying inconsistent values
- Checking data types
- Preparing data for analysis
- Ensuring data consistency

### 📈 Descriptive Statistical Analysis

Statistical analysis was performed to understand:

- Mean
- Median
- Minimum and maximum values
- Standard deviation
- Data distributions
- Numerical feature ranges

### 📊 Data Visualization

The project uses several visualization techniques:

- Bar Charts
- Histograms
- Box Plots
- Correlation Heatmaps
- Distribution Plots
- Category-based Comparisons

### 🔗 Correlation Analysis

The project analyzes relationships between nutritional attributes such as:

- Calories
- Sugar
- Carbohydrates
- Fat
- Protein
- Sodium
- Caffeine

> **Note:** Correlation represents an association between variables and does not imply causation.

---

## 🔍 Key Observations

- A strong relationship was observed between calories, sugar, and carbohydrate content.
- Frappuccino-based beverages generally contain higher calorie and sugar values.
- Brewed coffee and tea options generally contain fewer calories.
- Caffeine content varies across beverage categories and does not always follow the same pattern as calories or sugar.
- Nutritional attributes show different distributions across beverage categories.
- Correlation analysis highlights several relationships between nutritional variables.

## 🚀 How to Run

**1. Clone the repository**

```bash
git clone https://github.com/furqanzubair209-cell/Starbucks-Dataset-EDA.git
```

**2. Navigate to the project directory**

```bash
cd Starbucks-Dataset-EDA
```

**3. Install required libraries**

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

**4. Launch Jupyter Notebook**

```bash
jupyter notebook
```

Open `Starbucks Dataset EDA.ipynb` and run the notebook cells sequentially to reproduce the analysis.
